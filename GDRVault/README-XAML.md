# GDRVault — aggiornamento estetico XAML

Contiene 7 finestre XAML e `Controls.xaml`, dizionario condiviso.

Mettere `Controls.xaml` nella stessa cartella dei 7 XAML nel progetto GDRVault, come predisposto dai `ResourceDictionary Source="Controls.xaml"`.

Modifiche: stili condivisi, pulsanti viola coerenti, TextBox/PasswordBox altezza 48 e CornerRadius 5, focus viola, icona credenziale vettoriale migliorata. Nessun handler C# è stato rinominato o modificato.
